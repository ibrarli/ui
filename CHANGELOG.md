# Changelog

## 0.2.0 — 2026-11-11

- Expand the registry to 31 components with accordion, breadcrumb, pagination, collapsible, popover, radio group, slider, toggle and toggle group.
- Add interactive documentation examples for every new component.
- Fix collapsed sidebar alignment and mobile navigation, including focus trapping, dismissal and focus restoration.
- Fix navbar dismissal, short-screen dialogs, table/card overflow and progress bars with custom maximum values.
- Add browser regression tests for responsive layouts and keyboard interactions.
- Update package metadata and documentation links to the current GitHub repository.

## 0.1.0 — 2026-11-10

- Initial release with 22 components, bundled registry and init/add/list commands.
- Support TypeScript and JavaScript project output.
